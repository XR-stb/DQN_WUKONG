## 2026-09-01 修复复测

60 秒实战探针成功保存 64 步，但战斗循环仅 1.12Hz、deadline miss 100%、检测平均
648.81ms；输入队列平均 18.7 个，已消费输入平均滞后 11.24 秒，确认该回合不可训练。

将 WGC 隔离到独立进程后，以三个固定共享内存槽只传递最新帧；主进程不会排队接收旧帧。
同时采用高精度固定周期等待。10 秒只读复测结果：

| 指标 | 修复前实战 | 隔离后只读复测 |
|---|---:|---:|
| 观测循环 | 1.12Hz | 7.95Hz |
| deadline miss | 100% | 2.5% |
| HUD 检测平均 / p95 | 648.81 / 809.45ms | 0.58 / 0.70ms |
| 共享帧读取 p95 | 不适用 | 0.42ms |
| 帧龄平均 / p95 | 764.34 / 915.81ms（完成观测） | 59.42 / 100.81ms（共享帧发布） |
| 重复共享帧 | 不适用 | 1/80 |

复测处于 loading 场景，因此只验证吞吐和资源关闭，不验证战斗 HUD 准确率。采集子进程正常
回收，WGC 子进程内部仍打印其既有线程退出超时，但由进程边界负责最终回收。
另将脉冲动作改为在控制区间末尾采样：等待期事件丢弃，同一区间多个脉冲合并为最新一个，
不再把十几秒前的 FIFO 点击标到当前帧。正式战斗仍需再录一局确认输入 age 和 HUD 门槛。
